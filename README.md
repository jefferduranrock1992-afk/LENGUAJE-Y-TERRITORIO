# Lenguaje y territorio

**Repositorio digital educativo para contextos rurales colombianos**

## Propósito

Organizar y compartir recursos educativos digitales que fortalezcan la comprensión, la interpretación y la producción textual mediante contenidos relacionados con el territorio, el campo, la agricultura, la literatura, el deporte y la vida comunitaria.

## Categorías

1. Literatura y territorio
2. Campo y agricultura
3. Deporte y comunidad
4. Comprensión e interpretación textual
5. Producción textual
6. Recursos audiovisuales
7. Producciones estudiantiles

## Población

Estudiantes y docentes de contextos rurales colombianos.

## Estado

Prototipo educativo en construcción.
